# WiseMind: Virtual Standard Patients & Differential Diagnosis System

This repository contains the WiseMind prototype system, including:
- A web-based psychiatric diagnostic conversation agent
- A Virtual Standard Patient (VSP) generation pipeline
- DSM-inspired decision trees for differential diagnosis
- Example simulated interviews illustrating the full reasoning workflow

**The system is intended for research, demonstration, and reviewer evaluation purposes only.**

---

## 🚀 1. Running the WiseMind Web App

You can run WiseMind in two ways: **locally** (with your own API key) or through our **hosted demo URL**.

---

### **Option A — Run Locally (Recommended for Development)**

1. Install dependencies (via `conda` or `pip`) so that FastAPI, Uvicorn, and the OpenAI client are available.

2. Set your API key as an environment variable:
```bash
   export OPENAI_API_KEY="sk-..."
```

3. Navigate to the application directory:
```bash
   cd src
```

4. Start the server:
```bash
   uvicorn app:app --host 0.0.0.0 --port 8000
```

5. Open your browser to:
```
   http://127.0.0.1:8000
```
   or
```
   http://localhost:8000
```

## 🧪 2. Generating Virtual Standard Patients (VSPs)

We provide `src/generate_vsp.py` to construct VSP scripts—consistent, DSM-grounded, first-person patient profiles.

VSPs are generated from DSM-style diagnostic decision trees and include:
- A binary met/not-met vector over all DSM decision nodes
- A full, coherent first-person symptom narrative generated by an LLM
- One CSV per VSP with fields: `Node`, `Met_Criteria`, `Description`, `Patient_Story`

### **Usage**

From `src/`:
```bash
python generate_vsp.py --disorder mdd --vsp-id MDD_0
```

### **Command-line Options**

| Argument | Description |
|----------|-------------|
| `--disorder {mdd, anx, bp}` | Choose which decision tree to use.<br>`mdd` — Depressed mood tree<br>`anx` — Anxious mood tree<br>`bp` — Elevated mood / bipolar tree |
| `--vsp-id <ID>` | File identifier for the generated VSP (e.g., `MDD_0`) |
| `--diagnosis-name <LABEL>` | (Optional) Select leaf diagnosis by label (e.g., `"MDD"`) |
| `--leaf-path <PATH>` | (Optional) Use an exact tree path (advanced) |
| `--data-dir` | Where tree CSVs are stored (default: `../data`) |
| `--out-dir` | Where to save generated VSP CSVs (default: `../data/vsp_scripts`) |

### **Where VSP Files Are Saved**

Generated VSP profiles are stored under:
```
data/vsp_scripts/<vsp_id>.csv
```

We also provide example pre-generated VSPs:
```
data/Medical/example_vsp_<disorder>/
```

## 🎭 3. Example Simulated Interviews

In:
```
data/Medical/Example Simulated Interview/
```

you will find three example simulated WiseMind–VSP diagnostic sessions.

Each example JSON includes:
- Ground-truth disorder (`gt_disorder`)
- WiseMind's prediction (`pred_disorder`)
- Final and intermediate diagnostic accuracy
- The complete node-by-node reasoning path
- Node-level RA summaries and decisions
- Full multi-turn conversation transcript
- Reasoning logs for each question and action
- Inference time and number of rounds

### **These examples illustrate:**
- How WiseMind interacts with VSPs
- How the Structured Knowledge Graph (SKG) drives decision-making
- How reasoning and empathy are combined
- How final diagnoses are produced

## 🌳 4. Decision Trees & Structured Knowledge Graph (SKG)

### **4.1. Interactive Tree Notebook**

The notebook:
```
src/differential_diagnosis_tree.ipynb
```

demonstrates how we construct and manipulate the DSM-inspired binary decision trees used as the SKG.

It includes:
- Example tree construction
- DFS traversal and path extraction
- Visualization utilities
- Exporting trees to CSV for VSP generation

### **4.2. DSM Decision Tree CSV Files**

Each disorder category has a detailed decision-tree CSV:
```
mdd_tree_dfs_detailed.csv   # depressed mood
anx_tree_dfs_detailed.csv   # anxious mood
bp_tree_dfs_detailed.csv    # elevated mood / bipolar
```

Each row contains:
- `path`: hierarchical identifier (used to reconstruct parent-child relations)
- `name`: node label
- `Description`: clinical meaning of the decision node

These files are consumed by:
- `generate_vsp.py` (for VSP creation)
- WiseMind (for structured diagnostic reasoning)
- SKG visualisation scripts

## 🧭 5. Disorder Code Interpretation

Throughout the repository:
- `mdd` → depressed mood / major depressive pathway
- `anx` → anxious mood / anxiety decision tree
- `bp` → elevated mood / bipolar spectrum decision tree

These codes appear in file names, CLI arguments, and analysis scripts.
